# 小米电视无线实机测试

测试日期：2026-10-24。设备：Xiaomi MiTV-MTEQ0，无线 ADB，1080p。安装当前 Debug APK，保留原应用数据；没有创建 NAS 来源、修改登录信息或发起下载。

依据 implement-page Workflow 和 Android UI Skill 执行页面、焦点与滚动检查。本轮仅测试和记录，没有修改产品代码。

## 已验证

- 覆盖安装、冷启动和首页进入正常。
- 遥控器方向键可以从导航进入操作区及海报列表，确认键可进入详情。
- 英文片名按两行展示，详情完整显示片名；按钮图标可见。
- 详情页主次操作可见；从首页海报进入电影详情后可以开始 NAS 串流。
- 播放器显示视频画面；媒体会话状态为 PLAYING，进度推进，播放/暂停文字和图标切换正常。截图记录了约 3 秒至 4 秒的画面进度。
- 可以返回详情和首页，再切换媒体库、下载与本地页；NAS 浏览入口能打开，返回主页面正常。

## 未通过的视觉项

1. 首页初始首屏：海报图片外移后的标题区过低，长片名第二行及辅助信息不能完整进入首屏。主视觉与卡片整体高度仍需要按电视可用高度联合计算。
2. 首页下移焦点后：主视觉标题被滚入固定导航遮挡区，出现片名上半部分被截断的状态。停止预览更新并没有解决滚动构图问题。
3. 媒体库初始网格：搜索/筛选区占用较多高度，卡片图片与两行标题组合后，底部元数据进入列表裁切区域。需要联合调整网格列宽、封面高度与工具区密度。
4. 缺失封面仍显示为大块无信息表面；真实片库还存在绿色封面与测试色条。横向素材可以完整显示，但放入竖框后的空白较多，整体电影感不足。素材质量和图片布局策略应分别处理，不能伪造海报掩盖问题。

## 范围限制

- 本轮为真实片库的功能冒烟与视觉检查，不能视为全面回归通过。
- 没有验证可用字幕、多音轨选择结果、连续播放结束、长时间稳定性、断网重连、下载中断、存储拔插和大字体电视适配。
- 播放测试可能按既有逻辑更新观看进度；测试结束返回首页。
- 截图保存在 Git 忽略目录 app/build/outputs/ui/mi-tv/：home、cards、detail、player、player-running、library、downloads、final-home。
- 播放画面持续刷新时 uiautomator 未能取得空闲状态，未将该次层级抓取作为通过证据；播放验证使用截图和媒体会话状态。
