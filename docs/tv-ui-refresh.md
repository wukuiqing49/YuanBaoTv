# 电视媒体库界面改版

## 设计与实现

- 保留 XML、ViewBinding、现有媒体仓库、入口和资源名称。
- 公共资源采用中性深色表面、青绿主操作、白灰文字；来源徽章降低饱和度。
- 图标使用 Google Material Icons Round 的官方 SVG 转 Android VectorDrawable，许可证见 `feature/feature_res/MATERIAL_ICONS_LICENSE.txt`。下载来源：`https://github.com/google/material-design-icons`。没有生成或替换影视封面。
- 按钮保留主操作与次操作层级，统一圆角、按下、聚焦、禁用及触屏水波纹。Material 按钮通过 `icon` 属性展示图标，播放图标随状态更新。
- 首页导航叠加在背景上；主视觉使用底部 Barrier，保证内容增高时不覆盖下一排；简介限制宽度。最近加入保留十项，分类独立保留且每排最多十二项，完整内容仍在媒体库。
- 电视最近加入海报聚焦停留 250ms 后，仅在主视觉标题完整可见且未进入导航遮挡区时更新预览；深层分类不触发预览。离焦取消待执行预览；播放目标与预览目标保持一致，移除媒体后恢复默认目标。
- 没有横背景时，首页完整展示竖海报；缺图采用中性渐变。详情有独立海报，背景缺失时不再拉伸海报。
- 卡片使用明确圆角轮廓，并在布局完成后更新，兼容部分电视系统的状态背景轮廓缓存；列表留出缩放空间。
- 详情操作通过 Flow 排列，避免长文案在固定宽高按钮内换行裁切。播放器选择菜单采用 MaterialAlertDialogBuilder。
- 下载入口更名为“下载与本地”，对应本地导入、存储和下载职责。默认中文、简体中文与英文同时更新，无新增语言 fallback。
- NAS 按钮与图标、编辑和缓存弹窗、搜索与排序控件复用公共表面与状态。

## 资源匹配约定

Android 的 `sw` 和 `land` 限定符优先于 `television`。只维护 `layout-television` 不能保证横屏电视选中电视布局。

本次保持电视布局在以下目录一致：

- `layout-television`：电视基础布局。
- `layout-land-television`：覆盖普通横屏布局。
- `layout-sw600dp-land-television`：覆盖平板布局。

电视尺寸的四个 `values*television` 分支同步主视觉顶部与高度。后续修改电视布局时需要同步对应目录，避免再次误选手机或平板资源。

## 剩余验证范围

- 实机样本中存在纯色封面、测试视频和缺失简介；代码没有用虚构海报替代真实片库，电影感仍取决于实际素材质量。
- 未完成多品牌电视、极大字体、长英文、平板旋转、大片库性能、完整播放/字幕/音轨、下载中断与存储拔插的全量回归。
- 工作区原有 Manifest 与网络安全配置允许全局明文连接并信任用户证书，因此聚合构建规则检查失败。本次未修改这些网络策略；Debug APK 构建通过不代表该门禁通过。
- 架构检查提示既有 LocalSubtitleResolver 使用 Uri.fromFile；UI 检查提示多个 Activity 消费底部 Insets，需分别检查各窗口 owner，不能据此断言同一页面重复消费。

## 封面与文字第二轮调整

- 五套封面和继续观看布局同步拆分图片与文字，保留原有 id。图片按比例测量，两行片名使用统一行高与文字区最小高度，横排按内容测量，不再裁切新增文字区域。
- 封面图片由 Coil 成功回调判断宽高比；合适的竖图裁切铺满，横向剧照完整显示在中性表面中。缺图使用安静的中性占位，片名始终在图片外可读。
- 继续观看独立展示片名、集数和剩余时间；说明允许两行，进度条仍绑定真实观看进度。
- 卡片与详情共用元数据格式化，过滤空白、未知年份、重复分类，移除“电影 / 电影”和“- /”等展示。
- 详情主按钮使用“立即播放 / 继续播放”，季集目标移到单独说明，保留原播放逻辑。
- 电视首屏按有无观看历史设置不同背景高度；手机、平板和电视均通过 Barrier 避让增高内容；缺简介时不占据主视觉空间。
- 默认中文、简体中文和英文同步新增分隔符及剩余时间资源，无新增语言 fallback。
- 模拟器临时测试了四条合成数据：长中文、长英文、缺图、横图；检查了竖屏、1920×1080 横屏和 1.3 倍字体。合成图片仅用于比例验证，没有写入产品素材。数据库、分辨率、密度和字号在测试后恢复。
- 本轮没有打断电视当前前台界面，因此新版电视首屏比例、深层滚动和遥控器焦点门禁仍需实机复测，不能用模拟器横屏测试替代电视验收。


## 2026-10-24：首页五问题再次落实与实机验证

此前局部样式调整不足以解决整体首页，不能视为五项全部完成。本次重新调整：

1. 三个 TV 资源分支使用固定背景与透明渐变导航，统一中性黑灰、白色主要按钮。
2. 重新分配首屏空间；小米电视横排首次测量为零高，已为 TV 横排指定高度。
3. TV 首页使用 16:9 横卡，优先横向素材；缺图提供片名兜底，比例不符时完整容纳图片。主视觉背景仍需高质量横图。
4. HomeViewModel 将继续观看、最近添加与分类排去重，每排最多八项；同名分集按展示集合归并。完整媒体库不删除数据。
5. 图文分区，中文展示名去除英文附名、分集及画质尾缀；保留原始标题用于详情、索引。焦点采用白色描边与轻微放大，自动滚动留出完整卡片空间。

实机：无线 Xiaomi MiTV-MTEQ0，1920×1080，使用现有 YuanBaoTv NAS 真实片库，覆盖安装保留配置。已检查首屏继续观看封面/片名/进度、向下进入最近添加横排、焦点卡片底部与导航遮挡。截图：app/build/outputs/ui/home-redesign.png（首屏）、home-rows-final.png（最终横排）。

验证：assembleDebug 与 feature_app 单元测试通过（29 项）；UI 检查通过但仍提示既有多个 Insets owner；i18n 通过。新增展示处理未增加用户文案，原有语言资源与 fallback 保留。素材来自现有 NAS 及片库，不新增宣传素材；版权授权未做审核。

未完成/限制：索引层仍存在分集识别与季数错误（实机出现 40 季），片头截图、二维码等低质量素材尚未过滤；缺图兜底已实现但本轮未制造断网/坏图场景实测。手机与其他电视尺寸本轮未回归。电视缺少系统目录选择器的下载落盘限制不属于本次视觉修复。
