# Google Play 素材共同策略

## 输出目标

生成 `PLAY_ASSET_STRATEGY.md`，作为 Feature Graphic、Screenshots 和 Preview Video 的共同事实源。三个分支不得分别重新定义产品定位。

## 必填定位

- App Name
- Product Category
- Platform
- Primary Audience
- Primary User Problem
- Primary Value Proposition
- Primary Marketing Message
- Primary Differentiator
- Supporting Features
- Primary Keyword
- Secondary Keywords
- Target Locale

每个定位结论必须引用最终关键词分类和 VERIFIED Product Fact。

## Cross-Asset Message Map

按照以下职责分配信息：

- Feature Graphic：用一个核心信息说明 App 是什么。
- Screenshots：用真实页面证明核心能力、差异化和结果。
- Preview Video：用真实操作说明任务如何完成。

允许共享关键词和视觉语言，不重复同一句 Headline、同一画面或同一组功能标签。把素材关系设计成“定位 → 功能证明 → 工作流演示”。

## Shared Visual Style

从真实 App 资源和 UI 提取：

- Primary/secondary colors
- Light/dark direction
- Typography direction
- Icon style
- UI density
- Device frame direction
- Background direction
- Logo treatment

宣传设计只补充 App UI，不重新设计 App UI。无法从资源确认的风格标记为建议，不写成品牌事实。

## Demo Data System

使用一套可以在真实 App 中复现的 Demo Data 贯穿截图和视频。记录准备步骤、输入、状态、预期结果、版权来源和 PII 检查。

## 阻塞条件

出现以下任一情况时将状态标记为 `BLOCKED`：

- 核心定位依赖 UNVERIFIED 功能
- 缺少关键词工具结果且用户未确认既有定位
- 缺少需要展示的真实 UI
- 真实 App 与营销文档冲突
- 目标 Locale 没有对应真实 UI 或已确认文案
