# Android 国际化规则

- 用户可见文案默认放入 string 资源，不在 Kotlin、Java、XML 或 raw HTML script 中硬编码。
- 保持现有 key 命名、前缀和分组；优先复用同类 key。
- 格式化文案使用占位符，不手工拼接；数量相关文案使用 plurals。
- 默认语言与目标语言的占位符数量、顺序和类型必须一致。
- 新增或修改文案时，至少检查默认语言和已有同类 key 的语言文件。
- 项目语言目录以 `.agents/config/project-profile.yml` 为概览，以实际 `res/values*` 为准。
- 产品名、订阅、计费、法律、隐私和权限术语在多语言中保持一致。
- 无法提供可靠翻译时允许明确 fallback，但必须在结果中说明。
- raw HTML/WebView 文案单独检查 UTF-8、加载逻辑和内嵌脚本语法。
- PowerShell 读取本地化资源时使用 UTF-8；不得提交乱码或损坏占位符的文案。
